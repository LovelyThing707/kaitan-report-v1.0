02

学習セッションの状態遷移（満点法ロジック）

問題⇄解答の往復と巡目進行を、ステートマシン（状態と遷移が定義された処理機構）として表現します。OKは出題リストから除外、再チェックは次巡へ繰り越し、全OKで指定範囲終了に至ります。

stateDiagram-v2
  direction TB
  [*] --> 範囲指定
  範囲指定 --> セッション開始 : スタート / 初回OKを除く
  state セッション開始 {
    [*] --> 出題リスト構築
    出題リスト構築 --> ランダム並べ替え
    ランダム並べ替え --> [*]
  }
  セッション開始 --> 問題提示 : 巡目=1
  問題提示 --> 解答確認 : 意味・例文
  解答確認 --> 単語OK : OK
  解答確認 --> 単語再チェック : 再チェック
  単語OK --> 巡内判定 : リストから除外
  単語再チェック --> 巡内判定 : 次巡リストへ追加
  巡内判定 --> 問題提示 : 当該巡に未出題あり
  巡内判定 --> 結果表示 : 当該巡の全単語を出題済み
  結果表示 --> 問題提示 : 次に進む（再チェックあり・巡目+1で再構成）
  結果表示 --> 範囲指定 : 範囲再指定
  結果表示 --> 指定範囲終了 : 全OK（再チェックなし）
  指定範囲終了 --> スタート画面 : 演出後・自動（完了ブロック薄色化 / 回転数+1）
  スタート画面 --> [*]
03

範囲指定画面のブロック状態遷移

各ブロックは「未学習（白）→ 選択中（青）→ 完了（薄色）」と状態が変化します。完了後も再選択して再学習でき、リセットで白に戻ります。

stateDiagram-v2
  direction LR
  [*] --> 未学習_白
  未学習_白 --> 選択中_青 : タップ / 一括選択
  選択中_青 --> 未学習_白 : 再タップ（選択解除）
  選択中_青 --> 完了_薄色 : 当該ブロックの全単語OK
  完了_薄色 --> 選択中_青 : タップ（再選択して再学習可）
  選択中_青 --> 未学習_白 : リセット
  完了_薄色 --> 未学習_白 : リセット
完了後も「初回OKを除く」用に、1巡目の再チェック記録を保持します。

05

注記

  • ⑥問題画面 ⇄ ⑦解答画面 の往復は、操作速度を最優先するため遷移アニメーションを実質無し（100ms以下）とする。実装上は1画面内での表示切替とし、画面遷移の負荷を排除する。
  • ⓪キャラ選択画面・⑫Second stage は本MVPの対象外（点線表記）。将来、同一フレームワーク上で追加する。
  • 46ブロック全完了時も①スタート画面へ戻り、星評価が1回転分進む（詳細は仕様書「8. 星評価」）。
